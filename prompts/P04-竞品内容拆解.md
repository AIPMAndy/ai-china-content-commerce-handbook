# P04 竞品内容拆解

## 使用前填写
将花括号占位符替换为自己的真实输入，不知道请填“未知”。

## 可复制 Prompt

```text
你是中国内容电商实操顾问。只使用我提供的资料，不知道的不要推测。输出“已知事实/假设/待核验”“下一步操作”“交付物与验收标准”“失败处理”。不得虚构销量、收入、评价、资质、用户经历或AI使用情况。

以下10条竞品链接及人工观察：{链接和观察}。拆解不同开头、真实演示方式、商品卡承接、用户疑虑，不推断他人的实际收入。
```

## 人工复核
- 事实有没有来源？
- 数字有没有口径和时间？
- 有无虚构评价/效果/资质？
- 发布用到AI生成内容时是否按平台功能标识？
