GETTING STARTED

如何使用完整开源项目

网站无需安装；下载完整仓库后双击 site/index.html 即可离线阅读与计算。

网站包含什么

30章实操、37个有来源的商业案例、26个AI Prompt、6条经营路线、30天可勾选计划、商家/达人/服务商三种经济账。

需要编辑原始资料怎么办

  1. 回到压缩包根目录，打开 README.md。
  2. 到 docs/ 阅读平台操作、首单演练、红队审核、服务交付；到 templates/ 打开14个 CSV 工作表。
  3. 若要生成网站，运行 python scripts/build_data.py 和 python scripts/build_site.py。

如何发布到 GitHub Pages

在 GitHub 创建公开仓库 ai-china-content-commerce-handbook 并上传仓库全部文件（不是只传site目录）。打开仓库 Settings → Pages，将 Source 设为 GitHub Actions。仓库内 .github/workflows/pages.yml 会自动校验和部署。实际发布前不应将预测的网址当成可访问链接。

要注意什么

案例来源业绩不等于利润。平台资格和费率要以当前商家后台为准。AI生成合成内容按要求标识；真人试用、发货、售后不能由AI伪造。
