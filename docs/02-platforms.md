# 02｜五大平台怎么选，怎么从0开通

**先选平台，再查当前资格，最后决定做哪种内容。** 不要按一条不明日期的教程去猜需要多少粉丝、保证金、平台服务费：这些可能按账号、类目、活动和政策调整。

## 抖音：新商家实操

1. 打开抖音电商学习中心，按 **新商成长 → 入驻流程/开店指南** 进入；如果你走达人分销，选择对应的**达人课程**。
2. 比较个人、个体工商户、企业等入驻身份的实际可售类目；先看你要卖的商品是否开放，必要时咨询平台客服。
3. 用官方通道申请认证/店铺，完成后台开通（须以本人合法主体及授权商品为准）。
4. 进入商品运营，完成 1 个 SKU 的真实照片、规格、库存、物流、退货填写；先自己检查详情页是否清楚。
5. 创建 3 条实拍短视频，发布时检查商品关联选项是否实际出现。没有入口不要编造“可以挂车”。
6. 7天内记录每条内容的播放、商品点击、支付与退款；第7天决定保留还是调整。

## 小红书：图文/买手起步

1. 到官方学习中心检索 **新商冷启、商品笔记、橱窗、买手合作**；分清自己是买手还是店主。
2. 走商家路线的，在千帆核对主体资质、经营类目与保证金；走买手路线的，在当前创作者后台核对可用权限与佣金结算。
3. 一周内写2篇基于真实产品的场景笔记，展示实际优缺点，平台内完成商品关联。
4. 去 [千帆买手合作教程](https://school.xiaohongshu.com/lesson/normal/b19973a777764a729a69008e2744f1eb) 查选品、达人匹配和佣金入口。
5. 在笔记数据中区分“收藏/点赞”与商品点击、成交。笔记火了不表示赚钱了。

## 快手：实体商品的讲解场

1. 通过官方应用与商家中心核对开店/达人带货权限，记录当前资格页面和结算规则。
2. 选择一件能反复实物演示的商品，例如家居小用品。拍 3 条真实问题答疑视频。
3. 有直播资格后安排短场真实讲解，保留回放，并将高频提问剪辑成独立短视频。
4. 记录短视频给直播间的流量、商品点击、售后问题。不要模仿别人每天7小时直播的劳动强度。

## 视频号：老客户场景

1. 使用官方视频号/微信小店相关管理入口核验小店主体、商品类目和直播关联资格。
2. 对已同意接收内容的客户收集常见问题，拍一条解决实际问题的视频。
3. 在允许的功能内使用小店与视频号商品承接，不绕过平台要求。
4. 重点记录已有客户与新客各自的咨询、支付与复购，防止混淆。

## 淘宝：货架和直播同时做

1. 到淘宝官方学习中心学习新商/直播入口；先有合规 SKU 与完整详情页。
2. 从一个商品的使用场景与FAQ开始做30分钟直播讲解，直播回放整理为商品页的“常见问题”。
3. 用搜索、店铺商品卡与直播数据看各自的成交作用。

**本手册故意不硬编菜单层级、粉丝门槛或固定保证金数字。** 每次开通都要在当日官方后台验证，并把变化提交 Issue 更新教程。
