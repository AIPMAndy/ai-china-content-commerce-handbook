# 00｜零基础当天上手（60分钟）

## 先认识你自己属于谁

- **只会内容，没有商品**：先走达人/买手合作，资格未通过则先做样品演示和渠道调研，不能靠私下绕过平台交易。
- **有供应链**：走单个 SKU 自营试卖，直接承担产品质量、发货与售后责任。
- **已有客户或商家合作资源**：先走 B 端内容服务试点。不压库存，交付样片、数据诊断、周报与标准化 SOP。
- **有专业 IP**：粉丝购买需求不确定时，先征询问题再做产品；既有用户信任比单次佣金重要。

## 60分钟行动卡

| 分钟 | 操作 | 验收 |
|---:|---|---|
| 0–10 | 打开 `site/index.html` 选择路径 | 选了唯一的首月模式 |
| 10–20 | 打开相应平台的官方学习中心 | 保存本日开户/带货资格页面 |
| 20–35 | 找一个真实商品或一家目标商户 | 有产品/客户网址、图片、需求来源 |
| 35–50 | 打开利润计算器，替换模拟数据 | 已写明哪些数据是未知/供应商报价 |
| 50–60 | 选择第1天交付物写入执行日志 | 今天的真实证据可复查 |

## 最小的第一单测试

首个目标不是日入过万。是建立**一条可追踪的完整交易链**：真实问题 → 真实商品/服务 → 真实内容 → 合规展示 → 询问/下单 → 付款与结算 → 交付与售后 → 退款后贡献。前面任一项缺失时，记录为“未验证”，不能补编。

对于 B 端服务商，“一单”指真实合同/报价接受/实际收款与交付验收；一份无人回应的提案不是成交。
