# 04｜3类赚钱模型的单笔经济账

网站 `site/assets/model.js` 是计算器唯一运算来源，有自动测试。下面说明公式与使用限制。

## 1. 自营商品

设支付订单数 N，含优惠后支付单价 P，退货率 r，单件成本 C，正向发货 S、包装 W，退货增量损耗 L，平台费率 p，达人佣金率 a，广告费 A，人工费 H，其他固定费 F。

- 支付GMV = N×P
- 保留订单数 = N×(1−r)
- 退款后净成交额 = N×(1−r)×P
- 采购成本 = 保留订单数×C（**简化假定：退款货可以重新入库；损毁另计L**）
- 正向物流与包装成本 = 原支付订单数×(S+W)
- 退货增量损耗 = 退款订单数×L
- 平台+达人费 = 退款后净成交额×(p+a)（**按净额简化计费，实际平台/佣金结算规则不同需调整**）
- 税前净贡献 = 净成交额 − 采购 − 物流包装 − 退货损耗 − 平台达人费 − 广告 − 人工 − 其他固定费。

**这个模型不处理：** 增值税/所得税、采购存货时点与资金占用、平台费用特殊计提、退款后不返货或不能再售、跨月结算、贷款利息、价格补贴。它是交易经济性快速评估，不是会计报表。对于无法再次销售的退货品，需要把商品进价也计入单笔退货损耗。

## 2. 达人/买手佣金

实结可佣金额 = 支付订单额 × (1−退款率)；佣金收入 = 实结可佣金额 × 结佣比例；净贡献 = 佣金 − 样品 − 内容制作 − 广告 − 其他。

需要注意：实际佣金结算基础可能有优惠分摊、服务费、退款时序等差异，所有占位费率都以后台与协议为准。

## 3. B端服务商

税前净贡献 = 客户数×实收服务费 − 客户数×(单客户工时×人工时薪+单客户外包成本) − 工具/月 − 获客费 − 其他。

服务合同要约定：客户提供的原始素材、授权、历史数据、投流预算、商品和订单归属、交付次数、修改次数、验收、付款、取消/退款处理。不要口头担保GMV。

## 4. 压力测试如何做

同一个真实SKU至少算三份：正常值、退款率翻倍（不超过100%）、投流成本增加50%。正常情景都不能覆盖成本时，先不扩大预算。

## 5. 三个关键口径

- **GMV**：成交总额，未必等于最终实收。
- **ROI**：不同平台对ROI可能有不同的分子分母。广告ROI即便看起来高，也可能仍然亏钱。写出计算公式。
- **净贡献**：扣除上面假定成本后的试算结果，仍不代表税后经营净利润。
