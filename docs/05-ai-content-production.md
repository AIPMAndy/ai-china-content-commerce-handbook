# 05｜AI短视频生产线：一天如何做3条，不伪造商品

## 必须先收集的真实素材

1. 产品正面、背面、规格和包装的原片。
2. 核实过的商品说明、库存价格、发货范围与售后政策。
3. 至少一个真实使用场景、一条真正来自用户的问题。
4. 如果做对比，要有明确相同的测试条件；无法复现就不要把AI生成效果当实测。

## 90分钟操作链

- **0–10分｜找问题**：从需求研究CSV里选一个最常见问题，不选只有热度的词。
- **10–20分｜事实卡**：打开 `prompts/P16-商品合规事实检查.md`，逐项核对商品卖点。
- **20–35分｜三版脚本**：使用 `prompts/P08-三开头A-B测试.md`（文件实际按标题生成），让AI只改前3秒、其余镜头相同。
- **35–60分｜拍原片**：真人演示产品；拍规格和缺点镜头，留原始文件。
- **60–75分｜剪辑与字幕**：AI处理切点和字幕，人工复核所有数据；保存AI辅助日志。
- **75–90分｜发布前质检**：检查挂载入口、发货、售后、AI标识以及是否使用受权音乐/素材。

## 3种内容结构

**反差实验**：提出一个常见误解→展示真实对照→告诉用户适合谁。前提是对照能复现。

**避坑问答**：先讲一个你不建议购买的使用场景→展示限制→解释对哪种人合适。不要用假装劝退博点击。

**工厂/研发故事**：展示材料、设计草图、质检、失败品和成品过程；AI负责分镜，不取代真实工艺。

## 每条内容需要一张日志

`templates/ai_content_log.csv`：内容ID、AI辅助哪些步骤、使用工具、原始素材、事实核验、应当标识的处理、审核人、发布链接。AI不是“没有人知道”的隐身手段。

## 避免把规模当成绩

有服务商能批量生成很多素材，但一条能带来稳定净贡献的内容比一千条零成交视频更有价值。先从3条真实可重复的内容实验开始。
