# 12｜平台规则、AI标识与来源审计

这里不罗列猜测的“限流规则”或不存在的固定粉丝门槛。每次做生意前去当前官方后台确认。项目的规范与运营依据如下：

- [《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)，2025-09-01施行。用户发布AI生成合成内容时应主动声明并使用服务提供者提供的标识功能。
- [《直播电商监督管理办法》](https://www.cac.gov.cn/2026-01/07/c_1769516655383334.htm)，2026-02-01施行。涵盖经营者真实信息、商品与价格、宣传内容、售后、记录保存；第37条提到AI人物图像/视频直播持续提示。
- [GB 45438-2025《网络安全技术 人工智能生成合成内容标识方法》](https://std.samr.gov.cn/gb/search/gbDetailed?id=301E0388CB75788DE06397BE0A0AE1B4)，2025-09-01实施。
- [抖音官方学习中心](https://school.jinritemai.com/doudian/web/home) / [小红书学习中心](https://school.xiaohongshu.com/) / [淘宝官方学习中心](https://www.tbxuetang.cn/)。

## 发布前的8项证据检查

1. 商品名/规格/功能说明有证据。
2. 商品类目与主体资质适配（按现行后台）。
3. 使用实物原片或有明确来源的授权素材。
4. 没有AI生成的虚假买家、体验、成交与资质。
5. AI生成合成内容该标识的已经标识；直播AI人物符合持续提示要求。
6. 原价/优惠价/折扣的比较依据清楚。
7. 快递、退货、售后与经营者信息可查看。
8. 存储必要的经营与直播记录，按现行法律与平台规则执行。

## 案例来源等级

- A：政府规章、法律和平台官方操作规则，适用于资格/合规事实。
- B：上市公司披露/平台官方命名商家案例，用于归档平台或商家的自述结果，不等于独立财务审计。
- C：独立采访或公开媒体报道，用于学习具体动作，仍要区分当事人自述和记者验证。
- D：匿名商家或未披露时间/口径的宣传片段，只能作为观察线索，不能用来证明收益。

每个商家案例的**结果口径、来源、是否有AI应用证据**都记录在 `data/cases.json` 和 `research/` 对应文件。
