# 06｜商家运营SOP：从选品到客户收货

## 商品上线前必须通过的五关

1. **客群关**：至少10条与本品相关的公开真实需求记录。
2. **证据关**：原始样品、尺寸规格、适用限制、功效与质量证明相匹配。
3. **经济关**：采购含税报价、正向物流、包材、退货损耗、平台收费、佣金、广告预算，模型至少在正常情景不是负贡献。
4. **履约关**：明确每天可发货订单上限、库存更新周期、售后响应责任人。
5. **账户关**：类目资质、主体资格、商品挂载、结算与退款页面当日核对。

## 上架当天

- 用真实商品照片搭建规格页，明确数量、材质、尺寸、包装、使用限制。
- 用手机完成一条30–45秒真实演示。脚本与原始素材都归档。
- 在当前平台已授权功能内挂载商品；手动使用普通消费者视角检查能否看到商品信息（不以刷单来测试支付）。
- 设置售后FAQ与缺货时的自动通知/人工响应机制。

## 每天复盘

| 阶段 | 对应信号 | 优先修复动作 |
|---|---|---|
| 曝光低 | 推荐/搜索曝光 | 改开头和用户问题表达 |
| 播放高点击低 | 商品点击率 | 改真实卖点、商品挂载、详情页规格 |
| 点击高支付低 | 支付转化 | 检查真实价格、物流、质量、差评 |
| 订单高净贡献低 | 退货/广告/履约成本 | 停止扩量，重新谈供应链或选品 |
| 回购低 | 真实复购周期 | 先改善商品体验与售后，不盲目促销 |

## 每周复盘

输出1页纸：实际支付数、退款数、保留订单数、支付GMV、退款后成交额、成本、净贡献、同周期对照、最重要的一个行动。数据若无后台明细，就写未知；禁止用播放量代替成交。
